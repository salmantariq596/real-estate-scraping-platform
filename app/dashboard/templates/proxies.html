Monitoring & Logging
Every fetch now logs proxy_id, provider, attempt number, and latency — check logs/scraper.log for lines like [Scraper] fetch OK url=... proxy=static-0 provider=static attempt=1/3 latency_ms=812. This page reads live per-worker snapshots published to Redis (see app/scraper/proxy_manager.py::_publish_stats_snapshot), refreshed every 30s — so it reflects the actual scraper workers, not this dashboard process. The same data is available at /api/v1/scraper/proxy-stats.
